# プライバシーポリシー

更新：2026 年 10 月 24 日。連絡先：[84996057@qq.com](mailto:84996057@qq.com)。

対象は MediaGo デスクトップと Web/Docker です。以下の選択機能を含まない旧版では動作が異なる場合があります。セルフホストの運営者は自分のサーバーデータと設定を管理します。

## ダウンロードと保存

入力した URL、ヘッダー、任意の認証情報は、要求したダウンロードや解析のため、対象サイト、メディアサーバー、プロキシ、ツールに渡されます。選択した LAN サーバーも含まれ、相手は IP アドレス等を確認できます。統計を無効にしても、要求したダウンロード、ページ閲覧、更新確認は止まりません。

ファイル、履歴、お気に入り、設定、ブラウザー保存領域、診断ログは端末または設定したサーバーに保存されます。ログには URL やパスが含まれる場合があるため、共有前に確認・マスキングしてください。アプリの統計イベント経由でこれらを自動アップロードしません。内蔵ブラウザーのサイトには独自の Cookie とポリシーがあります。

## 任意の TalkingData 統計

Beijing Tendcloud Technology Co., Ltd. の TalkingData JavaScript/H5 SDK は、ビルドに統計用アプリ識別子が設定され、かつユーザーが同意した場合だけ読み込みます。未選択、設定読み取り失敗、識別子未設定では無効です。

アプリは機能利用イベント名とバージョン等を渡しますが、イベントにマシン ID、タスク ID、リソース URL、ファイル名、パスワード、API key、任意の追加パラメーターを付けません。第三者 SDK は IP、ブラウザー/OS の情報、言語、ページの文脈、セッション時刻、Cookie やブラウザー保存領域の識別子を処理する可能性があります。必ずしも匿名ではありません。[SDK ポリシー](https://www.talkingdata.com/sdkprivacy.jsp?languagetype=en_us)と[事業者ポリシー](https://www.talkingdata.com/privacy.jsp?languagetype=en_us)を確認してください。モバイル SDK の権限一覧を本デスクトップ/Web 実装の収集内容とみなさないでください。

目的は機能利用の把握と改善です。拒否してもダウンロードは制限されず、取得したメディアの内容を統計イベントに添付・販売しません。

## 選択と停止

Windows の対話型インストーラーでは新規インストール時は未チェックで、既存のユーザー設定があれば反映します。サイレントインストールや自動更新は同意を追加・変更しません。ポータブル版、macOS/Linux、未選択の既存ユーザーにはアプリ内の案内を表示し、選択するまで SDK は読み込みません。

設定の「Share usage statistics」で変更できます。無効化すると SDK のタイマーを停止するため画面を再読み込みしますが、Core のバックグラウンドダウンロードは継続します。送信済み要求は取り消せません。保存失敗はエラー表示し、成功したと偽りません。

選択は OS ユーザーごとのアプリデータ `MediaGo/analytics-consent`（Windows は `%APPDATA%\MediaGo\analytics-consent`）に保存します。Web/Docker はブラウザー・サイトごとの `mediago.analytics-consent.v1` を使用し、サーバー全利用者で共有しません。サイトデータ削除後は再同意まで無効です。

## 保持と問い合わせ

ローカル情報はアプリまたはデータフォルダーで削除するまで残ります。タスク削除とダウンロード済みファイル削除は同じではありません。停止の選択は保存されます。

TalkingData 側の保持期間・処理場所はそのポリシーとサービスアカウント設定に依存し、クライアントから特定の期間・国を確定または強制できません。未確認の期限・場所を約束しません。停止しても過去に送信したデータや全 SDK 保存領域を自動削除するわけではありません。

開示、訂正、削除等は **84996057@qq.com** に、バージョン、大まかな時期、要求内容を連絡してください。秘密情報や未加工ログは不要です。必要に応じ事業者と連携して対応を検討します。セルフホストでは運営者にも連絡してください。適用法上の権利を行使できます。

公式ドキュメントサイトは別サービスで、運用設定に Baidu Analytics と Google Analytics が含まれます。アプリの統計スイッチは外部サイトを制御しません。[Google](https://policies.google.com/privacy)、[Baidu](https://privacy.baidu.com/policy)のポリシーも参照してください。変更時は本ポリシーを更新します。[署名ポリシー（英語）](../en/code-signing.md)も公開しています。
