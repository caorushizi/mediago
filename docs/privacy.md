# 隐私政策

更新日期：2026 年 10 月 24 日。联系邮箱：[84996057@qq.com](mailto:84996057@qq.com)。

本政策说明 MediaGo 桌面端和 Web 界面（包括 Docker 自托管）的数据处理。以下统计控制适用于包含这些设置的版本；旧版本行为可能不同，请在升级时阅读本政策。自托管服务运营者负责其服务器数据及统计配置。

## 下载、浏览与本地记录

MediaGo 使用你提供的链接、请求头及可选认证信息执行下载或资源探测。请求会发送给相应网站、媒体服务器、代理和下载工具，包括你选择的内网服务器；对方可看到 IP 地址等网络信息。关闭统计不会阻止你请求的下载、更新检查或网页访问。

下载文件、任务记录、收藏、设置、浏览器存储和诊断日志保存在当前电脑或你配置的服务器。日志可能包含资源链接、文件路径和错误详情，请脱敏后再分享。应用事件统计接口不会自动向维护者上传这些记录。内置浏览器中访问的网站有各自的 Cookie 和隐私规则。

## 可选 TalkingData 使用统计

MediaGo 保留北京腾云天下科技有限公司的 TalkingData JavaScript/H5 统计接入。只有构建配置了统计应用标识，且你明确同意后，才加载 SDK。没有选择、读取偏好失败或未配置统计标识时均不启用。

启用后，应用会上报页面打开、下载操作、转换操作、检查更新等功能事件名称。应用事件封装不会附带机器标识、任务 ID、下载链接、文件名、密码、API Key 或任意自定义事件参数。加载 SDK 的请求包含统计应用标识和应用版本。

第三方脚本在界面中执行，可能处理 IP 地址、浏览器或操作系统特征、语言、页面上下文、会话及交互时间，以及 Cookie 或浏览器存储标识等信息。不能因为应用不再附带机器标识，就把统计当作完全匿名。详见 [TalkingData SDK 隐私政策](https://www.talkingdata.com/sdkprivacy.jsp?languagetype=zh_cn)及[集团隐私政策](https://www.talkingdata.com/privacy.jsp?languagetype=zh_cn)。移动 SDK 的权限清单不代表本桌面/Web 接入读取了手机标识。

统计用于了解功能使用情况、改进产品，是可选功能；拒绝不会限制下载。应用不会在功能事件参数中附带下载内容，也不会通过该封装出售下载内容。

## 选择和退出

- **Windows 交互安装器：**首次安装的统计复选框默认不勾选；存在当前 Windows 用户的历史选择时显示该选择。不勾选即记录拒绝。静默安装和自动升级保留原偏好，不代替用户同意。
- **便携版、macOS/Linux，以及没有记录选择的旧安装：**应用会显示提示，可同意统计或不启用而继续使用。选择前不加载 SDK。
- **设置 → 基础设置 → 分享使用统计：**随时修改。关闭后界面重新加载，销毁 SDK 已启动的计时器；Core 后台下载继续。已发送的请求无法撤回。
- **Web/Docker：**选择保存在当前浏览器、当前站点的存储中，不是全体服务器用户共享的开关。其他浏览器和桌面用户分别选择。清除站点存储后，统计恢复为关闭，直到重新同意。
- 保存失败会显示错误，不会声称新偏好已生效。你可以重试或退出应用。

桌面偏好存放在当前系统用户的应用数据目录下 `MediaGo/analytics-consent`；Windows 为 `%APPDATA%\MediaGo\analytics-consent`。Web 使用本地存储键 `mediago.analytics-consent.v1`。这些值仅表示偏好，不是认证凭据。

## 接收方、保存与删除

本地记录保留到你通过应用或删除相应应用/服务器数据进行清理。删除任务未必删除已经导出或下载的文件，请单独管理。关闭统计会保留拒绝偏好。

已启用的统计由 TalkingData 服务处理。服务端保留期和处理地点取决于供应商政策及对应服务账号设置，客户端无法确定或强制具体期限、国家或地区。我们不会承诺未经核实的保留期限或处理地点。撤回同意并重新加载后不再加载统计 SDK，但不会自动删除 TalkingData 已接收的数据，也不等于清除了过去会话创建的所有浏览器存储。

如需查询、更正、删除、撤回或了解历史统计，请联系 **84996057@qq.com**，说明应用版本、大致日期及请求类型。请勿发送密码、Cookie、API Key 或未脱敏的完整日志。维护者会评估请求，并在必要时联系服务商协助处理。自托管用户还应联系服务器运营者。你可以依法行使适用的数据权益。

## 官网和其他服务

公开文档网站与应用内的 TalkingData 开关相互独立。官网生产配置包含百度统计和 Google Analytics；评论及外链还可能连接你选择使用的 GitHub 等服务。这些服务按各自政策处理浏览器和网络信息。应用内开关不控制你在外部浏览器中访问的官网。可参阅 [Google 隐私政策](https://policies.google.com/privacy)和[百度隐私政策](https://privacy.baidu.com/policy)。

统计目的或范围发生变化时，将更新公开政策。软件签名状态见[代码签名政策](./code-signing.md)。
